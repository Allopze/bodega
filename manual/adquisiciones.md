# Solicitudes, aprobaciones, compras y recepcion

Indice de la seccion:

- [Solicitudes](./adquisiciones/solicitudes.md)
- [Aprobaciones](./adquisiciones/aprobaciones.md)
- [Compras](./adquisiciones/compras.md)
- [Recepcion](./adquisiciones/recepcion.md)
- [Entregas](./adquisiciones/entregas.md)

Este grupo cubre el flujo completo de adquisiciones: crear una solicitud,
aprobarla, generar la orden de compra y registrar la recepcion.

El orden habitual es:

`Solicitudes -> Aprobaciones -> Compras -> Recepcion -> Entregas`
