# Cuenta corriente

La pantalla `Cuenta corriente` sirve para revisar resúmenes y movimientos.

## Como usarla

1. Entra a `Combustibles > Cuenta corriente`.
2. Revisa el resumen mensual.
3. Haz clic en un registro para ver detalle.
4. Usa `Nuevo resumen` o `Registrar pago` segun corresponda.

`Registrar pago` aparece dentro del detalle de un resumen.
