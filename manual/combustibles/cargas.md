# Cargas de combustible

La pantalla principal de `Combustibles` muestra las cargas registradas.

## Como usarla

1. Entra a `Combustibles`.
2. Revisa los indicadores.
3. Filtra por fecha, vehiculo o proveedor.
4. Abre una carga para ver su detalle.

## Como crear una carga

1. Haz clic en `+ Nueva carga`.
2. Completa el formulario `Nueva carga de combustible`.
3. Pulsa `Registrar carga`.

## Como importar

1. Pulsa `Importar Excel`.
2. Sube el archivo.
3. Revisa el paso `Revisar datos`.
4. Confirma la importacion y espera `Completado`.
