# Documentacion preventiva

Esta seccion es la biblioteca documental de prevencion. Aqui se ordenan
archivos en carpetas, se crean nuevas versiones y se revisan documentos
pendientes.

## Pantallas disponibles

- `Documentacion`
- `Nuevo documento`
- `Revisiones`
- `Vencimientos`
- `Papelera`
- `Detalle documental`

## Como entrar

1. Abre `Prevencion`.
2. Entra a `Documentacion`.
3. Navega por las carpetas hasta encontrar el tema que buscas.

## Como crear una carpeta

1. En la pantalla principal de documentacion, pulsa `Nueva carpeta`.
2. Escribe el nombre.
3. Guarda.
4. Si hace falta, entra a la carpeta nueva y sigue ordenando archivos.

## Como subir un archivo

1. Entra a la carpeta correcta.
2. Pulsa `Subir archivo`.
3. En el modal `Subir documentos`, elige `Subir archivos` o `Subir carpeta`.
4. Selecciona los archivos en tu computador.
5. Espera el avance de carga.

Cada archivo se registra como documento. Si subes una carpeta completa, el
sistema recrea la estructura dentro de la ubicacion actual.

## Como ver un documento

- Haz clic en el documento de la lista.
- Revisa los datos generales.
- Abre la pestaña de versiones para ver historico de cambios.
- Usa `Ver / previsualizar` o `Descargar archivo`.
- Si tu rol lo permite, puedes `Archivar` el documento o `Subir versión`.

## Revisiones

La pantalla `Revisiones` muestra documentos que necesitan revision o control.

- Abrela para revisar pendientes.
- Entra al documento y valida si necesita correccion o aprobacion.

## Vencimientos

La pantalla `Vencimientos` sirve para vigilar documentos proximos a vencer.

- Revisa las fechas.
- Prioriza los documentos mas cercanos al vencimiento.
- Actualiza o renueva el archivo cuando corresponda.

## Papelera

La pantalla `Papelera` muestra carpetas y documentos archivados.

- Usa esta vista para recuperar algo que fue archivado por error.
- No la uses como espacio de trabajo normal.

## Consejo practico

Piensa esta seccion como una biblioteca:

- Carpetas para ordenar.
- Documentos para consultar.
- Versiones para controlar cambios.
- Papelera para recuperar archivos archivados.
