# Guia para Jefa Dpto. Prevencion de riesgos

Tu trabajo en la plataforma es controlar la parte preventiva: evaluaciones SST,
PPA Digital, programa preventivo, documentos, EPP y seguimiento general.

## Por donde empezar cada dia

1. Entra al `Dashboard`.
2. Revisa si hay tareas, alertas o actividades preventivas pendientes.
3. Abre `Prevencion`.
4. Revisa `PPA Digital` si hay casos nuevos o detenidos.
5. Revisa `Programa preventivo SG-SST` para ver actividades del periodo.
6. Revisa `Documentacion` si necesitas subir, ordenar o actualizar archivos.

## Evaluaciones SST

Usa `Prevencion > Evaluaciones SST` para revisar trabajadores y evaluaciones.

1. Abre `Evaluaciones SST`.
2. Busca el trabajador o la evaluacion.
3. Entra al detalle.
4. Revisa la lista de chequeo, plan de accion, seguimientos y acta.
5. Si corresponde, cierra la evaluacion cuando este completa.

Para crear una evaluacion:

1. Pulsa `Nueva Evaluación`.
2. Elige trabajador, faena y tipo de evaluacion.
3. Completa los pasos del formulario.
4. Revisa el resumen.
5. Guarda.

## PPA Digital

Usa `PPA Digital` para revisar formularios enviados desde terreno.

1. Abre `PPA Digital`.
2. Revisa los indicadores superiores.
3. Filtra por estado, faena o texto si necesitas encontrar un caso.
4. Abre el PPA.
5. Lee respuestas, motivos de alerta y linea de tiempo.
6. Registra la revision.
7. Si el caso ya esta resuelto, usa `Cerrar caso`.

Si necesitas entregar acceso al formulario:

1. En `PPA Digital`, usa el acceso del encabezado.
2. Elige la faena.
3. Copia el enlace o descarga el QR.
4. Comparte ese acceso con el equipo de terreno.

## Programa preventivo SG-SST

Usa `Programa preventivo SG-SST` para controlar actividades planificadas.

1. Entra a `Prevencion > Programa preventivo SG-SST`.
2. Elige año, programa, hoja y faena.
3. Revisa actividades atrasadas, pendientes y completadas.
4. Abre una actividad para registrar avance o evidencia.
5. Si una actividad requiere aprobacion, revisala antes de aprobar.

## Documentacion preventiva

Usa `Documentacion` como biblioteca oficial.

1. Entra a `Prevencion > Documentacion`.
2. Abre la carpeta correcta.
3. Usa `Nueva carpeta` si necesitas ordenar.
4. Usa `Subir archivo` para cargar documentos.
5. Abre un documento para revisar versiones, descargar o subir una nueva
   version.
6. Si un documento ya no debe usarse, archivalo en vez de borrarlo.

## EPP, recepcion y entrega

Cuando el flujo incluya EPP:

1. Revisa solicitudes en `Solicitudes`.
2. Aprueba o rechaza en `Aprobaciones`.
3. Revisa llegada de productos en `Recepcion`.
4. Usa `Bodega` para ver stock.
5. Usa `Entregas` para registrar entrega de EPP a trabajadores.

## Administracion que puedes necesitar

En `Administracion` puedes revisar datos maestros relacionados con prevencion:

- `Trabajadores`: mantener datos de trabajadores.
- `Faenas`: revisar lugares de trabajo.
- `Productos`: revisar productos y EPP.
- `Proveedores`: revisar proveedores.
- `Taxonomia documental SST`: ordenar tipos de documentos.
- `Catalogos PDTP`: mantener datos base del programa preventivo.

## Si algo no cuadra

- Si falta un trabajador, revisa `Administracion > Trabajadores`.
- Si falta un EPP, revisa `Administracion > Productos`.
- Si no encuentras un documento, revisa carpeta, busqueda y papelera.
- Si un caso no aparece, revisa filtros de faena, estado o fecha.
- Si sigue el problema, crea un caso en `Soporte`.
