# Guia para roles de terreno y comite

Esta guia sirve para `Administrador de contrato / Supervisor de faena`,
`Supervisor de faena`, `Jefe de terreno`, `Conductor lider` y miembros del
`Comite Paritario`.

Cada cuenta puede ver cosas distintas, pero la forma de trabajar es parecida:
revisar actividades de la faena, registrar avances y consultar documentos.

## Por donde empezar

1. Entra al `Dashboard`.
2. Revisa tareas o avisos.
3. Abre `Prevencion`.
4. Abre `Programa preventivo SG-SST` si debes registrar actividades.
5. Abre `Documentacion` si necesitas consultar archivos.

## Evaluaciones SST

Si tu rol participa en evaluaciones:

1. Entra a `Prevencion`.
2. Busca el trabajador.
3. Abre la evaluacion.
4. Completa la parte que te corresponde.
5. Guarda.

El `Conductor lider` normalmente participa en evaluaciones de acompanamiento
en terreno.

## Programa preventivo

1. Entra a `Programa preventivo SG-SST`.
2. Elige faena y periodo.
3. Busca la actividad.
4. Registra avance.
5. Adjunta evidencia si corresponde.

## Documentacion

1. Entra a `Documentacion`.
2. Abre la carpeta correcta.
3. Descarga o revisa el documento.

## Combustibles y vehiculos

Algunos roles de faena pueden consultar `Combustibles` o vehiculos. Usa estas
pantallas para revisar informacion, no para reemplazar registros formales de
mantencion o compra.

## Si no ves una opcion

Puede ser normal. La plataforma muestra solo lo necesario para tu trabajo. Si
crees que te falta acceso, avisa a tu jefatura o administracion.
