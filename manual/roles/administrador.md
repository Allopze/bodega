# Guia para Administrador

Tu trabajo es mantener la plataforma funcionando para todos: usuarios, roles,
faenas, productos, proveedores, parametros y soporte general.

## Por donde empezar

1. Entra al `Dashboard`.
2. Abre tu menu de usuario.
3. Entra a `Administracion`.
4. Revisa la seccion que necesitas mantener.

## Usuarios e invitaciones

1. Entra a `Administracion > Usuarios`.
2. Usa `Nuevo usuario` para crear una cuenta interna.
3. Usa `Invitar` para enviar o generar un enlace de registro.
4. Revisa invitaciones pendientes.
5. Usa `Reenviar invitacion` o `Cancelar invitacion` cuando corresponda.
6. Edita roles, faenas y estado del usuario con cuidado.

## Datos maestros

Mantén estos datos antes de pedirle al equipo que use la plataforma:

- `Faenas`
- `Trabajadores`
- `Productos`
- `Proveedores`
- `Centros de costo`
- `Catalogos de productos`
- `Catalogos de flota`
- `Taxonomia documental SST`
- `Catalogos PDTP`

## Configuracion y control

Usa estas pantallas solo cuando tengas claro el cambio:

- `Configuracion`
- `Parametros operativos`
- `Folios`
- `Seguridad y bloqueos`
- `Notificaciones`
- `Log de auditoria`
- `Configuracion de correo`
- `Plantillas de correo`

## Cuando alguien no puede trabajar

1. Revisa si el usuario esta activo.
2. Revisa si tiene el rol correcto.
3. Revisa si esta asignado a la faena correcta.
4. Revisa si la invitacion vencio, fue cancelada o ya fue usada.
5. Si el problema es de correo, revisa `Configuracion de correo`.

## Buenas practicas

- No dupliques productos, proveedores ni trabajadores.
- Desactiva registros que ya no se usan en vez de cambiarlos por otros.
- Revisa el `Log de auditoria` cuando necesites entender quien hizo un cambio.
- Usa `Soporte` para dejar registro de problemas de uso.
