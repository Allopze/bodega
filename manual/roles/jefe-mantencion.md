# Guia para Jefe de mantencion

Tu trabajo en la plataforma se concentra en repuestos, servicios, vehiculos,
mantenciones, combustible y seguimiento de compras asociadas.

## Por donde empezar cada dia

1. Entra al `Dashboard`.
2. Revisa pendientes.
3. Abre `Solicitudes` para crear o revisar pedidos.
4. Abre `Flota` o `Mantenciones` si necesitas revisar vehiculos.
5. Abre `Combustibles` si necesitas revisar cargas o consumos.

## Solicitar repuestos o servicios

1. Entra a `Solicitudes`.
2. Pulsa `Nueva solicitud`.
3. Elige `Repuestos` o `Servicios`.
4. Completa faena, urgencia, fecha requerida e items.
5. Adjunta o registra cotizaciones si corresponde.
6. Envia a aprobacion.

## Revisar compras y recepcion

1. Entra a `Compras` para revisar ordenes.
2. Abre una OC para ver proveedor, items y estado.
3. Entra a `Recepcion` para registrar llegada en faena cuando corresponda.

## Flota y mantenciones

1. Entra a `Flota` para ver ficha y antecedentes de vehiculos.
2. Entra a `Mantenciones` para planificar o registrar trabajos.
3. Usa `Nueva mantención`.
4. Completa vehiculo, proveedor, faena, fecha, tipo de servicio y observaciones.
5. Guarda.

## Combustibles

1. Entra a `Combustibles`.
2. Revisa cargas y consumos.
3. Usa filtros por fecha, vehiculo o proveedor.
4. Abre una carga si necesitas detalle.

## Buenas practicas

- Mantén las patentes y datos de vehiculos actualizados.
- Registra observaciones claras en mantenciones.
- Usa trazabilidad para seguir items desde solicitud hasta recepcion.
