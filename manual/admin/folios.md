# Folios

La pantalla `Folios` permite revisar secuencias de codigos y registrar
correcciones controladas.

## Como usarla

1. Entra a `Administracion > Folios`.
2. Revisa la secuencia que quieres auditar.
3. Aplica una correccion solo si detectaste un salto o desajuste real.
4. Guarda la correccion.

Evita modificar folios sin respaldo, porque afectan codigos de documentos y
registros operativos.
