# Catalogos PDTP

La pantalla `Catalogos PDTP` mantiene responsables, hojas y programas base del
Programa de Trabajo Preventivo SG-SST.

## Como usarla

1. Entra a `Administracion > Catalogos PDTP`.
2. Elige la pestana que necesitas revisar.
3. Crea, edita o desactiva el registro.
4. Guarda.

Usa esta seccion antes de crear o ajustar programas preventivos.
