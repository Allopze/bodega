# Roles

La pantalla `Roles` permite revisar y mantener roles base, alcance y permisos
incluidos por rol.

## Como usarla

1. Entra a `Administracion > Roles`.
2. Revisa la lista de roles disponibles.
3. Abre la edicion del rol que quieras ajustar.
4. Cambia nombre visible, alcance o permisos, si tu permiso lo permite.
5. Guarda los cambios.

El rol `administrador` esta protegido para evitar dejar el sistema sin acceso
administrativo.
