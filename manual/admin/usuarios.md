# Usuarios

La pantalla `Usuarios` sirve para crear cuentas, invitar personas y cambiar el
acceso de cada usuario.

## Botones principales

- `Nuevo usuario`
- `Invitar`
- `Reenviar invitacion`
- `Cancelar invitacion`
- `Editar`
- `Activar` o `Desactivar`

## Como crear un usuario

1. Entra a `Administracion > Usuarios`.
2. Haz clic en `Nuevo usuario`.
3. Completa nombre, correo y demas datos.
4. Asigna rol, permisos y faenas.
5. Guarda.

## Como invitar a alguien

1. Entra a `Administracion > Usuarios`.
2. Haz clic en `Invitar`.
3. Completa el formulario de invitacion.
4. Envia la invitacion.
5. Si el correo esta configurado, la persona recibira un enlace para crear su
   acceso.
6. Si el correo no esta configurado, copia el enlace que muestra la plataforma
   y compartelo por un canal seguro.

## Como gestionar invitaciones

1. Entra a `Administracion > Usuarios`.
2. Revisa el panel de invitaciones recientes.
3. Usa `Reenviar invitacion` para generar un nuevo envio o enlace.
4. Usa `Cancelar invitacion` si ya no debe poder usarse.

## Como editar un usuario

1. Busca al usuario en la lista.
2. Haz clic en el icono de editar.
3. Cambia los datos necesarios.
4. Guarda los cambios.

## Como activar o desactivar

1. Busca el usuario.
2. Presiona el boton de estado.
3. Confirma el cambio si aparece una ventana.

## Importante

- Si ves `Pendiente`, la persona todavia no termina de configurar su clave.
- Una invitacion cancelada, reemplazada, vencida o ya aceptada no sirve para
  registrar una cuenta.
- Si el usuario tiene varios roles o permisos, el sistema los muestra como
  etiquetas en la tabla.
