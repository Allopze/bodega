# Proveedores

La pantalla `Proveedores` mantiene el registro de empresas con las que compra
el sistema.

## Como crear un proveedor

1. Entra a `Administracion > Proveedores`.
2. Haz clic en `Nuevo proveedor`.
3. Completa razon social, RUT y datos de contacto.
4. Guarda.

## Como editarlo

1. Busca el proveedor en la lista.
2. Haz clic en editar.
3. Corrige la informacion.
4. Guarda los cambios.
