# Taxonomia documental SST

Esta pantalla administra categorias y tipos documentales para la biblioteca de
prevencion.

## Como usarla

1. Entra a `Administracion > Taxonomia documental SST`.
2. Revisa las categorias existentes.
3. Crea o edita categorias y tipos de documento.
4. Ajusta vigencia o confidencialidad por defecto cuando corresponda.
5. Guarda.

Estos datos aparecen al clasificar documentos preventivos.
