# Catalogos de productos

Esta pantalla mantiene datos auxiliares del catalogo de productos, como
unidades de medida, atributos reutilizables y reglas del catalogo.

## Como usarla

1. Entra a `Administracion > Catalogos de productos`.
2. Abre la seccion que necesites ajustar.
3. Crea o edita el dato maestro.
4. Guarda.

Estos catalogos alimentan los formularios de productos y solicitudes.
