# Trabajadores

La pantalla `Trabajadores` centraliza el personal usado en entregas,
evaluaciones y otros flujos operativos.

## Como usarla

1. Entra a `Administracion > Trabajadores`.
2. Haz clic en `Nuevo trabajador`.
3. Completa nombre, RUT, cargo y faena.
4. Guarda.

## Para que sirve despues

- El trabajador puede aparecer en `Entregas`.
- Tambien puede aparecer en `Evaluaciones SST`.
