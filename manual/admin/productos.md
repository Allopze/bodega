# Productos

La pantalla `Productos` administra el catalogo que se usa en solicitudes,
compras y bodega.

## Como crear un producto

1. Entra a `Administracion > Productos`.
2. Haz clic en `Nuevo producto`.
3. Completa nombre, SKU y categoria.
4. Agrega precio de referencia y atributos.
5. Guarda.

## Que puedes ajustar

- Categoria.
- Proveedor de referencia.
- Precio.
- Si es EPP.
- Si requiere control de prevencion.
