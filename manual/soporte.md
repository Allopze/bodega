# Soporte

La seccion `Soporte` sirve para enviar reportes, dudas, errores o sugerencias.

## Que puedes hacer

- Crear un reporte nuevo.
- Revisar tus propios reportes.
- Ver el estado de cada caso.
- Agregar o leer comentarios de seguimiento.

## Como crear un reporte

1. Entra a `Soporte`.
2. Haz clic en `Nuevo reporte`.
3. Escribe el titulo.
4. Elige el tipo de reporte.
5. Describe el problema o la sugerencia.
6. Guarda el caso.

## Como revisar un reporte

- En la lista, abre el reporte que quieras seguir.
- Mira el panel de estado para saber si esta abierto, en curso o cerrado.
- Revisa los comentarios antes de escribir una nueva observacion.

## Consejo practico

Si un error bloquea tu trabajo, crea el reporte con una descripcion concreta:
que hiciste, que esperabas y que paso en realidad. Eso acelera la ayuda.
