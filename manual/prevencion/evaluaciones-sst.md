# Evaluaciones SST

La pantalla `Evaluaciones SST` agrupa evaluaciones por trabajador.

## Como usarla

1. Entra a `Evaluaciones SST`.
2. Busca un trabajador o abre una evaluación existente.
3. Pulsa `Nueva Evaluación` para crear una nueva.
4. Completa los pasos del formulario.
5. Revisa el resumen antes de cerrar.

## Dentro del detalle

- Información general con dos medidas diferentes: `Avance` indica las
  respuestas completadas y `Cumplimiento` solo los ítems que ya tienen
  resultado.
- Lista de chequeo.
- Plan de acción.
- Seguimientos.
- Acta.

Si faltan respuestas aplicables, el cierre muestra la sección y el primer
ítem pendiente. Usa `Ir al siguiente pendiente` o `Completar pendientes` para
llevar el foco al selector de sección y continuar. Solo cuando no queden
pendientes se habilita `Cerrar evaluación`; después del cierre queda en solo
lectura.
