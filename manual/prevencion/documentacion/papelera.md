# Papelera

La pantalla `Papelera` muestra carpetas y documentos archivados.

## Como usarla

1. Entra a `Documentacion > Papelera`.
2. Revisa lo archivado.
3. Usa `Restaurar` para recuperar carpetas o documentos.
4. Deja lo demas archivado.

Al restaurar una carpeta, vuelve a su ubicacion. Al restaurar un documento,
queda como borrador.
