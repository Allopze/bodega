# Manual de usuario

Este manual esta escrito a partir del codigo actual de la plataforma. Explica la
aplicacion por modulos, con lenguaje simple y pasos pensados para usuarios sin
conocimientos tecnicos.

## Como leer este manual

- Empieza por [Guia general](./guia-general.md) si es tu primera vez.
- Usa el archivo de cada modulo segun lo que necesites hacer.
- Si una pantalla no te aparece, normalmente es por permisos de tu cuenta.
