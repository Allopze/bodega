# Aprobaciones

La pantalla `Aprobaciones` concentra lo que esta pendiente de revision.

## Como usarla

1. Entra a `Aprobaciones`.
2. Abre el grupo de solicitud.
3. Revisa los items pendientes.
4. Pulsa `Aprobar` para un item o `Aprobar todos` para la solicitud completa.
5. Confirma con `Confirmar aprobación` cuando aparezca el formulario.
6. Pulsa `Rechazar` si el item no corresponde.
7. Si rechazas, escribe el `Motivo del rechazo`.

## Modo de despacho

En algunas solicitudes veras `Modo de despacho`. Revisa ese valor antes de
aprobar, porque define si la compra ira via oficina o directa a faena.
