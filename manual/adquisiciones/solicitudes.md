# Solicitudes

La pantalla `Solicitudes` es el punto de partida del flujo de compras.

## Como usarla

1. Entra a `Solicitudes`.
2. Pulsa `Nueva solicitud`.
3. Completa `Faena`, `Tipo de solicitud`, `Urgencia`, `Fecha requerida` y
   `Notas generales` si corresponde.
4. Usa `Agregar ítem` para sumar productos o descripciones.
5. En cada item completa `Descripción`, `Cantidad`, `Unidad`, `Urgencia`,
   `Proveedor sugerido` y observaciones cuando aplique.
6. Pulsa `Guardar borrador` si aun no esta lista.
7. Pulsa `Enviar a aprobación` cuando quieras enviarla al flujo.

## Acciones comunes

- Ver detalle.
- `Duplicar solicitud`.
- `Cancelar solicitud`, cuando el estado lo permite.
- Eliminar, si tu rol lo permite.
- Filtrar por estado, faena o texto.

## Tipos de solicitud

- `EPP`
- `Otro`
- `Repuestos`
- `Servicios`

`Repuestos` y `Servicios` pueden incluir cotizaciones. Revisa tambien
[Repuestos y servicios](../repuestos-y-servicios.md).
