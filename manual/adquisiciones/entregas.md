# Entregas

La pantalla `Entregas` registra la salida de EPP hacia trabajadores.

## Como usarla

1. Entra a `Entregas`. El formulario de registro aparece abierto arriba y el
   historial debajo. Tambien puedes usar `Registrar entrega` desde la barra
   superior para abrirlo y enfocarlo.
2. Selecciona faena.
3. Selecciona trabajador.
4. Elige el EPP pendiente.
5. Ingresa cantidad y guarda.

Si solo quieres consultar el historial, pulsa `Ocultar` para plegar el
formulario; la plataforma recuerda tu preferencia. Para volver a registrar,
pulsa `Registrar entrega`.

Al guardar, el formulario se limpia, permanece disponible para la siguiente
entrega y la pantalla vuelve al historial actualizado.
